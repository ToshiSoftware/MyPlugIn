# MyPlugInHost

MyPlugIn.app holds every MyPlugIn effect as an AUv3 extension
("Toka: MyReverb", ...) so that other hosts such as Logic can use them.
MyDAW does not need it: it has the effects built in.

`MyPlugInHost.xcodeproj` and `Extensions/<Name>/` are generated by
`Tools/make-host-project.py` from `Package.swift`; run it after adding an
effect (`Tools/new-plugin.sh` does). `HostApp/` and
`Extensions/Extension.entitlements` are edited by hand.

## Install

1. Open `MyPlugInHost.xcodeproj`, scheme **MyPlugIn**, Product > Archive
   (or Build), signed with your team.
2. Copy `MyPlugIn.app` to `/Applications` and open it once.
3. Check: `auval -v aufx MRev Toka`, `auval -v aufx MDly Toka`.

Remove the app to uninstall. While it is installed, MyDAW lists both
"MyDAW: MyReverb" (built in) and "Toka: MyReverb" (this app).
