# MyTuner 設計書

主にギター用のクロマチックチューナー。AU（MyPlugIn のほかのエフェクトと同じ形）として作るが、MyDAW ではチャンネルに
インサートせず、トランスポートバーのメトロノームの横の**音叉ボタン**で開け閉めする独立したウィンドウとして使う。
参考: Studio One の Tuner²（針のメーター、Hz・cents の表示、音名、▶ ◀ の合わせ込み表示、Strobe、Calibration）。
Sources: `Sources/MyTuner`、tests: `Tests/MyTunerTests`。

| 項目 | 値 |
|---|---|
| 名前 | MyTuner（MyDAW では "MyDAW: MyTuner"） |
| Subtype | `MTun`（一度決めたら変更不可。既存: MRev, MDly, MStp, MMax, MChP） |
| 型名プレフィックス | `Tuner...`（MyDAW は全ソースを 1 モジュールでコンパイルするため） |
| AU の種類 | エフェクト（`aufx`）。音はそのまま通す（加工しない）。Logic などではインサートでも使える |
| レイテンシ／テール | 0／0 |
| エディタ | 300 × 300 px（§1）。MyDAW のウィンドウはその上に入力の行（30 px）が付く |
| 対象の音域 | 約 30〜1,500 Hz（7 弦・ドロップチューニングの低音から、ギターの 24 フレットの倍音より上まで） |

### 改訂履歴

- ドラフト 1: 初版（2026-10-11）。
- ドラフト 2（2026-10-11）: ユーザーの回答で確定。モードは Chromatic と Guitar（標準チューニング）の 2 つ。
  メーターは**針が動く形**。Strobe は初版に入れる。インサート一覧からは外す（MyDAW 側で `MTun` を除く）。
  基準音は入れない。ベースは Chromatic で測る（専用モードなし）。
- 実装 1（2026-10-11）: ドラフト 2 どおり実装。ドラフトからの変更・補足:
  - ピッチ検出はカーネルではなくエディタ側（60 Hz のタイマー）で行う。カーネルは間引いた信号をリングに書くだけ（§3.4）。
    Logic などでインサートしたときも、オーディオスレッドの負担がフィルタだけで済む。
  - 周期の精度: 放物線補間に加え、周期の整数倍の谷でも補間して倍数で割る（高い音ほど効く）。
    差分関数は FFT ではなく vDSP の直接計算（1 回 約 40 万回の積和で十分軽い）。
  - 信頼度の下限はしきい値 0.12 そのもの（谷が 0.12 を下回らなければ「音なし」。0.85 の別判定は持たない）。
  - 解析は約 21 ms ごと（新しいサンプルが 21 ms 分たまるたび）。
  - モードのメニューはヘッダの右（ほかの MyPlugIn と同じ位置）。下段は STROBE と CAL（−／＋ で 0.5 Hz、ダブルクリックで入力）。
  - 入力デバイスが無いときの「入力なし」は、MyDAW 側の入力の行に出す（AU はホストの入力を知らないため）。入力の行は高さ 30 px。
  - テスト結果: 正弦波 41〜1,480 Hz・44.1／48／96 kHz で誤差 ±0.5 cent 以内、基音の弱い倍音の多い音で ±1 cent 以内・オクターブ誤りなし。

## 0. 使い方（マニュアルの元）

- トランスポートバーの **音叉ボタン**（メトロノームの右）を押すとチューナーが開き、もう一度押すと閉じる。
  ウィンドウの赤いボタンで閉じてもよい（音叉ボタンも消灯する）。
- ウィンドウ上部の **入力** メニューで、ギターをつないだ入力チャンネルを選ぶ。
- 弦を 1 本ずつ弾く。中央に音名、針が中央より左なら低い（▶ が点灯）、右なら高い（◀ が点灯）。
  ±2 cents 以内に入ると針と音名が緑になり、▶ ◀ が両方点灯する。
- 基準ピッチ（A4）は **Calibration** で 430〜450 Hz から選ぶ（標準 440 Hz）。
- **Strobe** をオンにすると、針の代わりに流れる縞で表示する（止まって見えたら合っている）。微調整向き。
- チューナーを開いていても音は変わらない（録音・再生中も使える）。

## 1. GUI

### 1.1 ウィンドウ

- MyDAW のプラグインウィンドウと同じ、タイトルバー付きのウィンドウ（タイトル「Tuner」）。閉じる（赤）ボタンのみ有効、
  サイズ変更なし。中身は AU のエディタ（300 px 幅）＋ MyDAW 側の入力メニューの行（§4.3）。
- ほかのプラグインウィンドウと同じく、メインウィンドウより手前に浮く。位置はアプリに記憶する（次回も同じ場所）。
- 起動時は閉じた状態（開いていたかどうかはプロジェクトにもアプリにも保存しない）。

### 1.2 レイアウト（幅 300 px）

```
┌──────────────────────────────────────┐
│ 🎤 [入力 1 ▾]                      │ ← MyDAW 側の行（§4.3）
├──────────────────────────────────────┤
│ MyTuner                               │ ← ヘッダ（ほかの MyPlugIn と同じ見た目）
│   ╭───────────────────────────╮      │
│  -50 ct        │          +50 ct      │ ← メーター（扇形の目盛、針）
│   ╰──────╱────┼────────────╯         │    約 280 × 120 px
│                                      │
│        ▶      A₂      ◀              │ ← 合わせ込みの矢印と音名（大きく）
│                                      │
│   109.6 Hz    │   −6.0 cents          │ ← 周波数と差
│   Frequency       Difference          │
├──────────────────────────────────────┤
│ [Chromatic ▾]  [Strobe]  Cal 440.0 Hz │ ← モード、Strobe、Calibration
└──────────────────────────────────────┘
```

### 1.3 メーター

- 参考画像と同じ、下に膨らんだ弧（−50〜+50 cents）。目盛は 10 cents ごとに短線、0 に長い中心線、両端に「−50 ct」「+50 ct」。
- **針**: メーターの下の外（弧の中心）を支点に、弧まで伸びる細い線。ずれ ±50 cents で左右に約 ±40° 振れる。
  0 の位置には短い中心の目印を残す。
- 色: 通常は MyDAW のアクセントの青、±2 cents 以内で緑、音が無いときは全体を暗く（針は中央で薄く）。
- 動き: 表示は 60 Hz で更新。値はなめらかに追従（時定数 約 80 ms）。音が切れたら最後の値を 0.5 秒保って、
  その後ゆっくり暗くなる（弦を離した瞬間に表示が消えないように）。

### 1.4 Strobe 表示

- Strobe オンのとき、メーターの弧の内側に縞模様の帯を出し、ずれ（cents）に比例した速さで流す（低い → 左へ、高い → 右へ）。
  ±1 cent 以内でほぼ止まる。数値と音名の表示はそのまま。

### 1.5 音名・矢印・数値

- 音名は英語表記（C, C♯, D … B）、オクターブ番号を右下に小さく（A4 = 440 Hz の表記。ギターの 6 弦開放は E₂）。
- ▶（低い）／◀（高い）: ずれが ±2 cents を超えた側だけ点灯（青）。±2 cents 以内は両方緑で点灯。
- Frequency: 小数 1 桁（例: 109.6 Hz）。Difference: 符号付き小数 1 桁（例: −6.0 cents）。音が無いときは「—」。

### 1.6 下段の操作

- **モード**（メニュー）: Chromatic（最も近い半音に合わせる）／Guitar（6 本の弦 E₂ A₂ D₃ G₃ B₃ E₄ のうち最も近いものに合わせる。
  音名の横に弦番号を表示）。→ §6。
- **Strobe**（トグル、オンでオレンジ）。
- **Calibration**: 数値をドラッグまたはダブルクリックで入力（MyPlugIn 共通の `MyFXEditableValue`）、0.5 Hz 刻み、430〜450 Hz。

アドレスは保存されるので、一度決めたら変更不可。

|---|---|---|---|---|
| 0 | `calibration` | Calibration | 430〜450 Hz | **440 Hz** |

## 3. 信号処理

### 3.1 入力

- 音はそのまま出力へコピー（エフェクトとしては素通し）。
- 解析はモノラル: ステレオで入ったら L+R の平均。MyDAW からは選んだ入力チャンネル 1 本がモノラルで入る（§4.2）。
- 内部で 1/4（48 kHz なら 12 kHz）に間引いて解析する（ローパス後に間引き。1,500 Hz までなら十分で、計算量が 1/16 程度に減る）。

### 3.2 ピッチ検出（YIN 法）

- 解析窓: 間引き後のサンプルレートの 85 ms 分（12 kHz で 1,020 サンプル）＋最大の周期（30 Hz）。約 21 ms ごとに 1 回検出。
- 差分関数 → 累積平均正規化 → しきい値（0.12）を最初に下回る谷 → 放物線補間で周期を小数まで求める（YIN の標準手順）。
  差分関数は vDSP で直接計算する。
- 周期の仕上げ: 差分関数は周期の整数倍でも谷になるので、窓に入るいちばん大きな倍数 k の谷も放物線補間し、k で割る
  （補間の誤差が 1/k になる。高い音ほど k が大きい）。
- 信頼度: 1 − 正規化差分。谷がしきい値を下回らなければ「音なし」。
- ゲート: 窓の RMS が −60 dBFS 未満なら検出しない（ノイズで針が暴れないように）。
- オクターブ誤り対策: 直前の結果のちょうど 2 倍／1/2 に近い値が 1 回だけ出たら採用しない（2 回続いたら採用）。
- 精度の目標: 82.4 Hz（E₂）〜1,000 Hz の正弦波・ギター録音で誤差 ±0.5 cent 以内。

### 3.3 音名と cents

- MIDI ノート番号 n = 69 + 12 log₂(f / Calibration)。Chromatic: 最も近い整数 n、ずれ = (n_実数 − n) × 100 cents。
- Guitar: 6 弦の開放（E₂=40, A₂=45, D₃=50, G₃=55, B₃=59, E₄=64）のうち最も近いもの。±50 cents を超えたら針は端で止める。

### 3.4 エディタへの受け渡し

- カーネルは間引いた信号をリング（8,192 サンプル、書き込み数は 1 語の値）に書くだけ。エディタが 60 Hz のタイマーで
  新しいサンプルが 21 ms 分たまっていれば最新の窓をコピーして検出する（`TunerAnalyzer`）。
  cents・音名の計算、針の平滑化・保持・フェード、Strobe の位相もエディタ側（`TunerDisplayState`）。
  Calibration・モードの変更がすぐ表示に反映される。
- エディタが見えていない間は、カーネルはリングに書かず素通しだけにする（CPU を使わない）。

## 4. MyDAW 側

### 4.1 音叉ボタン

- `TransportBarView` のメトロノームのトグルの右に、同じ大きさ（34 × 28）・同じ形（`.toggleStyle(.button)`）のトグル。
  アイコンは SF Symbols の `tuningfork`（macOS 13 で使える）。オンのときの色はシアン（メトロノームのオレンジと区別）。
- ヘルプ文字列: 「Show/Hide Tuner」／「チューナーの表示／非表示」（en/ja の Localizable と docs/UI_Strings_en_ja.csv に追加）。
- 状態は `AudioEngineManager.isTunerVisible`（@Published）。ウィンドウの赤ボタンで閉じたときも false に戻す。

### 4.2 音のつなぎ方（グラフに入れない）

- チューナーの AU は AVAudioEngine に **アタッチしない**。既にある入力のタップ（`processInputAudioBuffer`、全入力チャンネルが来る）から、
  選んだチャンネルのサンプルを AU の `renderBlock` に直接渡して処理させる（pull 入力のブロックでタップのバッファを返す）。
  理由: 動いているエンジンのグラフをつなぎ替えると、接続待ちや衝突が起きる（過去の Reverb 無音、メーター停止の原因）。
  タップ経由なら再生・録音中に開け閉めしても音の経路に一切触れない。
- AU はウィンドウを初めて開いたときに 1 つだけ作り、以後は閉じても保持（2 回目以降はすぐ開く）。
  `allocateRenderResources` はハードウェアのサンプルレート・モノラル・最大フレーム数＝入力バッファサイズで行い、
  サンプルレートやバッファサイズが変わったら（`setupEngine` のたび）作り直す。
- タップのスレッドで `renderBlock` を呼ぶのは、ウィンドウが見えている間だけ。
- 入力デバイスが無い（`hasInput` が false）ときは、入力の行に「入力なし」と表示。

### 4.3 入力の選択

- AU のエディタの上に、MyDAW 側で 1 行（高さ 30 px）の入力メニューを付ける: マイクのマーク（トラックヘッダの入力と同じ）＋
  モードのメニューと同じ見た目の欄（`MyFXMenuPicker`）「入力 1 ▾」（2026-10-11 ユーザー指示で変更）。
  中身はトラックの入力メニューと同じハードウェアチャンネルの一覧（モノラル 1 本ずつ）。
  → AU 自体はホストの入力を知らなくてよい（Logic などでは挿したチャンネルの音を測る）。
- 初期値: 選択中のトラックが録音待機なら、その入力チャンネル。それ以外は前回選んだチャンネル（無ければ 1）。
- 選んだチャンネルと AU の状態（Calibration・モード・Strobe の `fullState`）は、アプリの設定（UserDefaults）に保存する。
  プロジェクトには保存しない（チューナーはプロジェクトではなくギターの道具のため）。

### 4.4 一覧に出さない

- `MyPlugInCatalog.registerAll` で登録はするが、MyDAW のインサート用プラグイン一覧からは外す（チャンネルに挿す物ではないため）。
  MyDAW の一覧作成で subtype `MTun` を除く（§6）。

## 7. テスト

- 検出: 正弦波・のこぎり波（倍音が多い）で 41〜1,500 Hz、44.1／48／96 kHz のそれぞれで誤差 ±0.5 cent 以内。
- ギターの弦の音に近い信号（減衰する倍音列、基音が弱い）でオクターブを間違えない。
- −60 dBFS 未満・白色雑音で「音なし」。音が止まってから 0.5 秒は最後の値を保つ（エディタ側のロジックの単体テスト）。
- 音名と cents: Calibration 430／440／450 Hz で A4 が 0 cent、境目（±50 cent）の丸め、Guitar モードの弦の選択。
- 素通し: 出力が入力とビット単位で一致。AU のパラメータ一覧とエディタの大きさ。
- MyDAW: 再生・録音中にチューナーを開け閉めしても音が途切れない／メーターが止まらない。赤ボタンで閉じると音叉ボタンが消灯。
