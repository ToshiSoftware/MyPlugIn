# MyChannelStrip 設計書

DAW の各トラックに挿す標準チャンネル・ストリップ。
Sources: `Sources/MyChannelStrip`、tests: `Tests/MyChannelStripTests`（予定）。

| 項目 | 値 |
|---|---|
| 名前 | MyChannelStrip（MyDAW では "MyDAW: MyChannelStrip"） |
| Subtype | `MStp`（一度決めたら変更不可） |
| 型名プレフィックス | `ChannelStrip...`（MyDAW は全ソースを 1 モジュールでコンパイルするため） |
| 信号経路 | IN → [4 バンド EQ ⇄ コンプレッサ]（順序切替可）→ 出力 GAIN → OUT |
| レイテンシ / テール | 0 / 0 |
| エディタ | 300 × 464 px（チャンネル名の行、セクションごとに ON/OFF の見出し行。`MyFXAudioUnit.editorSize` で指定） |
| 負荷 | フラットな EQ バンド・OFF のコンプ・0 dB の出力 GAIN は計算しない（§3.0） |

### 改訂履歴

- ドラフト 2: EQ を 4 バンドに。フラット時はフィルタを通さない。処理順（EQ→COMP / COMP→EQ）切替を追加。
  Low/High Cut に 12 / 24 dB/oct のスロープ選択を追加。コンプ初期 OFF を確定。
- ドラフト 3: コンプ転送曲線上に出力レベルの ◯ 印を追加（§1.5）。
- 実装 1: 本書どおり実装（2026-10-09）。ソース構成は §4。
- 実装 2: LINK → STEREO LINK、AUTO → AUTO GAIN に改称。EQ / COMP の ON/OFF を各セクションの見出し行へ移し、エディタを 300 × 440 に。
- 実装 3: タイトルの下に枠付きで「CH:チャンネル名」を表示（全エフェクト共通、MyPlugInCore）。名前はホストが AU の contextName で渡す（MyDAW はトラック名・FX チャンネル名・MASTER）。エディタは 300 × 464、MyReverb / MyDelay は 300 × 424。
- 実装 4: チャンネル名の「CH:」を削除し、トラック名だけを表示（名前がないときは「-」）。

### 1.2 ヘッダ

- **処理順ボタン** `[EQ▸COMP]` / `[COMP▸EQ]`: クリックで切替。
  順序に合わせて EQ セクションとコンプセクションの **上下の並びも入れ替える**
  （画面の上から下が信号の流れ、という見た目を保つ）。
- `[EQ●]` `[COMP●]`: セクション ON/OFF（OFF のセクションは暗く表示し、処理もしない）。

### 1.3 EQ グラフ（Waves EQ のイメージ）

- 横軸 20 Hz〜20 kHz（対数）、縦軸 ±18 dB。グリッド 63 / 250 / 1K / 4K / 16K Hz と ±9 dB。
- 合成周波数特性を緑の線と半透明の塗りで描く。選択中バンドの単独特性を薄く重ねる。
- バンドは番号付きの丸ノード。OFF のバンドはグレー、選択中は黄色のカッコ付き（添付画像の ④）。
  **フラットで計算していないバンドはノードを中抜き（輪だけ）で描く**（負荷ゼロが目で分かる）。
- 背景にスペアナ（§3.5）を 20 本の棒で描く。

| 操作 | 効果 |
|---|---|
| ノードをクリック | そのバンドを選択（下の操作行が切り替わる） |
| ノードを横ドラッグ | FREQ |
| ノードを縦ドラッグ | GAIN（Low Cut / High Cut では Q＝肩のピーク） |
| ノード上でスクロール / ⌥+縦ドラッグ | Q |
| ⇧+ドラッグ | 微調整（1/10） |
| ノードをダブルクリック | バンド ON/OFF |
| ⌘+クリック | そのバンドの GAIN を 0 dB に戻す |

GAIN は ±0.3 dB 以内で 0.0 dB に吸着する（ドラッグで正確にフラットへ戻せる → 計算が止まる）。
ドラッグ中はノード横に「2.5 kHz / +4.4 dB / Q 1.0」を出す。オートメーション記録のため
ドラッグ開始で `.touch`、終了で `.release` を送る（`MyFXEditorModel.set(_:_:event:)`）。

### 1.4 バンド操作行

`[⏻ ON] [バンド番号]  (GAIN) (FREQ) (Q)  [タイプ 5 アイコン]`

- バンド番号ボタンはクリックで 1→2→3→4 と巡回（グラフで選んでも同じ）。
- ツマミは縦ドラッグ、ダブルクリックで数値入力（既存 `MyFXEditableValue`）、⌥クリックで初期値。
- タイプ: Low Cut / Low Shelf / Bell / High Shelf / High Cut（各 18 px アイコン）。
- **Low Cut / High Cut のときは GAIN ツマミの位置に SLOPE 切替 `[12|24]` を出す**
  （Cut では GAIN を使わないので、幅を増やさずに収まる）。

### 1.5 コンプ転送曲線（Studio One Compressor のイメージ）

- 120 × 120 px、入力 −60〜+6 dB（横）× 出力 −60〜+6 dB（縦）、12 dB ごとのグリッド。
- 静特性（threshold / ratio / knee / makeup を含む）を線で描く。ニー区間は 2 次曲線で滑らかに。
- 曲線上の **ハンドル（threshold 点）**:
  - 横ドラッグ → THRESHOLD、縦ドラッグ → RATIO（上へで 1:1 に近づく）
  - ⌥+ドラッグ / スクロール → KNEE
- 曲線上の **RATIO ポイント（●）**: スレッショルドより上の直線部、入力 0 dB の位置
  （スレッショルドが −6 dB より上なら、スレッショルド +6 dB の位置）。縦ドラッグで RATIO が変わり、
  ポイントがマウスの高さに付いてくる（ニー込みで逆算）。ここ以外の場所をドラッグすると、スレッショルドのハンドルと同じ動きになる。
- **出力レベルの ◯ 印**（コンプがかかる領域に音量が届いているかを目で掴むためのもの。精度は求めない）:
  - 折れ線の上を動く直径 7 px の輪。位置は x = 入力レベル、y = その入力に対する曲線上の出力値
    （makeup 込み）。常に線の上に乗るので「今どこで鳴っているか」だけが分かる。
  - レベルはコンプ検出部と同じ信号（LINK on なら L/R の大きい方）のピークを使い、
    表示用に立ち上がり即時・下がり約 20 dB/s で平滑（メータと同じ動き）。
  - 色: ニーより下（`x < T − W/2`）は白、ニー内は黄、ニーより上（圧縮中）はオレンジ。
  - −60 dB 未満は左下端に止めて薄く表示。COMP OFF 中も入力レベルに合わせて動かす
    （THRESHOLD を決めるときの目安になる）。ハンドル（threshold 点）とは形・色で区別する
    （ハンドルは塗りつぶし、◯は輪だけ）。
- COMP OFF のときは曲線を 1:1 の直線で描く（音は素通しなので）。ハンドルは THRESHOLD 設定用に直線上に薄く残し、◯ は白。
- 曲線の右に縦の GR（ゲインリダクション）メータ 8 px、0〜−24 dB、上から下へ伸びる。
- ツマミ: THR RAT KNEE / ATK REL MAKE（2 段 × 3）、トグル: AUTO（オートメイクアップ）・LINK（ステレオリンク）、MIX。

### 1.6 出力 GAIN

横フェーダ 1 本、±24 dB、ダブルクリックで 0 dB。0 dB 付近 ±0.3 dB で吸着。
既存フェーダは縦なので、横版 `StripHorizontalFader` を新設（後で Core に移せる形で書く）。

## 3. 信号処理

### 3.0 フラット時に計算しない仕組み

各ブロックは「通す / 通さない」をカーネル内で判定し、通さないときは **乗算もフィルタもせず入力をそのまま次へ渡す**。

| ブロック | 計算しない条件 |
|---|---|
| EQ バンド | OFF、または Shelf / Bell で GAIN が 0.0 dB（スムージング後の値も 0 に着いている） |
| EQ 全体 | EQ OFF、または 4 バンドすべてが上記 |
| コンプ | COMP OFF |
| 出力 GAIN | 0.0 dB（スムージング後も） |

- Low Cut / High Cut は GAIN に関係なく音を変えるので、ON なら常に計算する。
- **切り替わりでクリックを出さない**:
  - 計算 → 停止: GAIN が 0 dB へスムージングされ、係数が恒等（b = a）に着いた時点で止める。
    この時点で出力は入力と一致しているので段差は出ない。止めたらフィルタ状態をクリア。
  - 停止 → 計算: 状態ゼロから始める。直後の係数はほぼ恒等なので出力はほぼ入力のまま。
  - ON/OFF・TYPE・SLOPE の切替（特性が飛ぶもの）は旧系統と新系統を 10 ms クロスフェード。
    クロスフェード中だけ両方計算し、終わったら不要な方を止める。
- 判定はブロック（16 サンプル）単位。判定自体のコストは比較数回で無視できる。

### 3.1 EQ

- RBJ Audio EQ Cookbook の双 2 次（biquad）、Transposed Direct Form II、状態は Double。
  - Low/High Cut 12 dB/oct: 2 次 HPF/LPF 1 段。Q 0.71 でバターワース、上げると肩にピーク。
  - Low/High Cut 24 dB/oct: 2 次を 2 段縦続。Q 0.71 のとき 4 次バターワース
    （段の Q = 0.541 と 1.307）。Q を上げると 2 段目の Q を同じ比率で上げて肩のピークを作る。
  - Low/High Shelf: シェルフ（Q をスロープ係数として使用）。
  - Bell: ピーキング。
- 係数計算は純粋関数 `StripBiquad.coefficients(type:slope:freq:gain:q:sampleRate:)` にし、
  **カーネルとエディタのグラフ描画で同じコードを使う**（表示と音のズレをなくす）。
- パラメータ変化は 1 極スムージング（約 20 ms）で追い、16 サンプルごとに係数を再計算。
  値が止まっていれば再計算もしない。
- 既知の限界: 双一次変換のため 44.1 kHz で 15 kHz 以上のベルが狭くなる。必要なら後で
  Vicanek の matched 係数に差し替え（係数関数 1 つの変更で済む）。

### 3.2 コンプレッサ

フィードフォワード、ログ領域（Giannoulis / Massberg / Reiss 2012 の構成）。

1. 検出: LINK on なら `max(|L|, |R|)`、off なら各チャンネル独立。dB に変換。
2. 静特性（ソフトニー、T=threshold、R=ratio、W=knee）:
   - `x < T − W/2` → `y = x`
   - `|x − T| ≤ W/2` → `y = x + (1/R − 1)(x − T + W/2)² / (2W)`
   - `x > T + W/2` → `y = T + (x − T)/R`
3. ゲイン低下量 `g = y − x` を attack / release の 1 極スムーザ（分岐型、dB 領域）で平滑。
4. MAKEUP（AUTO on なら `−(T − T/R)/2` を自動加算）。
5. MIX: `out = dry·(1−m) + wet·m`（ドライ＝コンプの入力。パラレル圧縮用）。
6. COMP ON/OFF は 10 ms でクロスフェード。OFF 後は計算しない（§3.0）。

ルックアヘッドは入れない（レイテンシ 0 を保つ。必要になれば latency 報告込みで後から追加）。

### 3.3 処理順（`order`）

- EQ▸COMP: IN → EQ → COMP → OUT GAIN。COMP▸EQ: IN → COMP → EQ → OUT GAIN。
- 切替時は MyDelay の MODE 切替と同じ方式: 出力を 10 ms でフェードアウト → 順序を入れ替え・
  コンプのエンベロープとフィルタ状態をクリア → 10 ms でフェードイン。合計 20 ms の小さな凹みで、クリックは出ない。
- 演奏中の切替もオートメーションも可能（ただし上記の凹みが入る）。

### 3.4 出力 GAIN

dB → リニア、20 ms スムージング。最後段。0 dB では乗算しない（§3.0）。

### 3.5 スペアナ（2 band/oct）

- 対象は **EQ の出力**（処理順にかかわらず。EQ を動かした結果が見える）。L+R を 1 本にまとめる。
  EQ が計算停止中でもタップ位置は同じ（素通しの信号を表示）。
- レンダースレッドはロックなしの SPSC リングバッファ（8192 サンプル）に書くだけ。
  エディタが閉じている間は書き込みも止める。
- エディタ側（メイン、30 Hz）で最新 4096 点に Hann 窓 → vDSP FFT → パワーを
  20 Hz〜20 kHz の 1/2 オクターブ帯 20 本に集計 → dB 化。
- 表示: 帯ごとに +3 dB/oct の傾き補正（ピンクノイズが水平に見える）、
  立ち上がり即時・下がり 20 dB/s、上限 0 dBFS、下限 −72 dB。

### 3.6 エディタへの受け渡し（レンダースレッド → UI）

既存の `MyFXMeterPeaks` と同じ方式で、カーネルが次を公開する:

| 値 | 用途 |
|---|---|
| 入出力ピーク | IN / OUT メータ（既存のまま） |
| GR 最大値（前回取得以降） | GR メータ |
| 検出部の入力ピーク（前回取得以降の最大） | 転送曲線上の ◯（y は UI 側で静特性から計算） |
| 計算中のバンド（ビットマスク） | ノードの塗り / 中抜き |
| スペアナ用リングバッファ | §3.5 |
| サンプルレート | EQ グラフの係数計算 |

## 5. テスト

- フラット時に計算しない: 初期状態・全バンド GAIN 0・COMP OFF・OUT 0 dB で、出力が入力と
  **ビット単位で一致**。計算中バンドのビットマスクが 0。
- フラット⇄計算の切替: GAIN 0 → +6 → 0 dB を動かしながら隣接サンプル差の上限（クリックなし）、
  0 dB に戻った後にビットマスクが 0 に戻る。
- EQ: ベル中心周波数でのゲインが設定値 ±0.1 dB／Cut 12・24 の −3 dB 点と遠方の減衰
  （1 オクターブ先で約 −12 / −24 dB）／カーネルの実測応答（サイン掃引）と係数関数の理論値の一致。
- コンプ: 静特性の各区間（ニー下・ニー内・ニー上）、attack/release の時定数、
  LINK on/off、AUTO makeup、MIX 0 % で素通し、COMP off で素通し。
- 処理順: EQ▸COMP と COMP▸EQ で結果が異なる（ブースト EQ＋コンプで確認）、切替時にクリックなし。
- 出力 GAIN ±24 dB、モノラル（1ch）動作、バイパス、状態の保存・復元、
  アドレス・identifier の重複なし。
- スペアナ: 1 kHz サインで 1 kHz 帯が最大。
