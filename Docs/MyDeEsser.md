# MyDeEsser 設計書

ボーカルの子音（サ行・シ・ツなどの歯擦音）だけを弱めるディエッサー。
信号をクロスオーバーで「子音の帯域（高域）」と「それ以外」に分け、高域だけを先読みリミッタで抑えてから足し戻す（スプリットバンド型）。
Sources: `Sources/MyDeEsser`、tests: `Tests/MyDeEsserTests`。

| 項目 | 値 |
|---|---|
| 名前 | MyDeEsser（MyDAW では "MyDAW: MyDeEsser"） |
| Subtype | `MDes`（一度決めたら変更不可。既存: MRev, MDly, MStp, MMax, MChP, MTun） |
| 型名プレフィックス | `DeEsser...`（MyDAW は全ソースを 1 モジュールでコンパイルするため） |
| 信号経路 | IN → INPUT GAIN → クロスオーバー（LR4）→ 低域 ＋ 高域 × 子音リミッタのゲイン（先読み 2 ms）→ OUT |
| 検出 | 高域（子音帯域）のピーク。STEREO LINK ON: L/R の大きい方で左右共通 / OFF: 左右独立 |
| レイテンシ | 先読み 2 ms 固定（48 kHz で 96 サンプル）。AU の `latency` で報告し、MyDAW が補正する |
| テール | 0 |
| エディタ | 300 × 500 px（`MyFXAudioUnit.editorSize` で指定） |
| 負荷 | フィルタ 3 段 × ch ＋ ゲイン計算 × ch。INPUT GAIN 0 dB は乗算しない |

## 0. 使い方（マニュアルの元）

MyDeEsser はボーカルの「サ行」が耳に刺さるときに、その部分だけを弱めるエフェクト。ボーカルトラックに挿す
（EQ・コンプの後ろが基本）。

| つまみ・ボタン | 役割 |
|---|---|
| INPUT | 入力の音量。THRESH はこの後のレベルで判定するので、小さい素材は INPUT を上げてもよい |
| FREQ | 子音の帯域の下限。これより上の音だけを抑える。女性ボーカルは 6〜8 kHz、男性は 4〜6 kHz が目安 |
| THRESH | 子音の帯域がこのレベルを超えた分だけ抑える（リミッタ）。下げるほど強くかかる |
| ATTACK | 抑え込むまでの時間。0 ms＝子音の頭から確実に抑える。長くすると子音の頭が少し残り、自然になる |
| RELEASE | 抑えた後に戻る時間。短いと子音の後の響きまで戻りが速い。長すぎると次の音の高域まで沈む |
| STEREO LINK | ON: 左右を同じだけ抑える（定位が動かない）。OFF: 左右を別々に抑える（左右で別の歌のとき） |
| LISTEN | 子音の帯域だけを聴く。FREQ を決めるときに使い、終わったら OFF に戻す |

基本の手順:

1. LISTEN を ON にし、FREQ を動かして「サ行」がいちばんはっきり聞こえ、母音がほとんど聞こえない位置にする。LISTEN を OFF に戻す。
2. 歌を再生しながら SIB メータ（子音帯域のレベル）を見る。サ行のところで大きく振れる。
3. THRESH を下げていき、サ行のときだけ GR（子音の抑えた量）が 3〜8 dB 程度振れる位置にする。
   母音のところで GR が振れるなら下げすぎ。
4. 抑えすぎて「舌足らず」に聞こえたら THRESH を上げる、または ATTACK を少し長くする。

先読みのため出力は 2 ms 遅れるが、MyDAW が自動で補正するので他のトラックとずれない。

### 1.2 IN / OUT メータ

- 既存の `MyFXMeterRow`（`showsClip: true`）。L/R 2 本、−96〜+6 dB の MyDAW テーパ、1.5 s ピークホールド、
  最大値の読み値と CLIP ランプはクリックでクリア。
- **IN は INPUT GAIN の後**（このプラグインが判定に使うレベル）。IN と OUT を見比べると、
  子音のところだけ OUT が下がるのが分かる。
- MyDeEsser は音量を上げないので、OUT の CLIP は IN が CLIP したときだけ点く。

### 1.3 帯域グラフ（284 × 90 pt）

- 横軸 500 Hz〜20 kHz（対数）、グリッド 1k / 2k / 5k / 10k / 20k。縦軸 +3〜−24 dB、グリッド 0 / −6 / −12 / −18 dB。
- FREQ の位置に縦の点線。点線から右（子音の帯域）を薄い赤で塗る。
- 現在の周波数特性 `|L(f) + g·H(f)|`（g は子音リミッタの今のゲイン、§3.3）を白い線で描き、
  0 dB との間（＝今抑えている量）を赤で塗る。30 Hz で更新するので、サ行で右側が沈むのが見える。
  g は GR メータと同じ動き（§1.4）。STEREO LINK OFF のときは L/R のうち深い方を描く。
- 点線を横にドラッグすると FREQ が変わる（`.touch` / `.release` 付き。⌘で微調整、⌥クリックで初期値）。
- LISTEN 中は右上に黄色で `LISTEN` と出す。バイパス中は線をグレーで 0 dB に描く。

### 1.4 SIB / GR メータ

- **SIB**（子音帯域のレベル）: 高域のピーク。L/R 2 本、−60〜0 dB をリニア（dB）で。
  THRESH の位置に赤い縦線（2 px）。THRESH を超えた部分のバーを赤、それ以下を青緑で描く
  （「どこから抑えるか」と「今どれだけ超えているか」が一目で分かる）。
  赤い縦線は横にドラッグして THRESH を動かせる（フェーダと同じ扱い）。
  落ち方は IN/OUT メータと同じ（約 20 dB/s、1.5 s ピークホールド）。読み値は最大値、クリックでクリア。
- **GR**（子音のゲインリダクション＝子音コンプレッションレベル）: L/R 2 本、0〜−24 dB、**右端（0 dB）から左へ** 赤く伸びる。
  STEREO LINK ON では 2 本は同じ長さ。30 Hz の更新ごとの最大 GR を表示し、レベルメータの本体と同じく
  深くなるときは即座に、戻るときは約 20 dB/s で戻る。
  読み値は最大 GR（例 `-6.3`）、クリックでクリア。24 dB を超える GR もバーは左端で止め、読み値は実際の値。
- 目盛は SIB 用（−60〜0、12 dB ごと）。GR は「右端 0、左端 −24」の別目盛なので、GR の行の左端に小さく `-24` を添える。

計 7 パラメータ（ホストでの並びは上の表の順）。`MyFXParameter` の 1 enum（`DeEsserParameter`）にまとめる。

スムージング（ジッパーノイズ防止）:
- INPUT GAIN・THRESHOLD: 20 ms の 1 極。
- FREQUENCY: log(Hz) 領域で 20 ms の 1 極。変化中だけフィルタ係数をサンプルごとに再計算（TPT 型なので動かしても安定、§3.2）。

- LISTEN / バイパス: 10 ms のクロスフェード。STEREO LINK: 切替はゲインの平滑（§3.3）を通るので、そのままで飛ばない。

## 3. 信号処理

モノラル（1 ch）でも同じ処理。内部状態は Double、オーディオは Float。

### 3.1 INPUT GAIN

dB → リニア、スムージング後に乗算。0.0 dB（スムージング後も）なら乗算しない。IN メータはこの後の値を測る。

### 3.2 クロスオーバー（Linkwitz-Riley 4 次、24 dB/oct）

- 2 次 Butterworth（Q = 1/√2）の TPT ステート・バリアブル・フィルタ（Zavalishin 型、プリワープ付き）で組む。
  1 段目が LP と HP を同時に出し、LP をもう 1 段の LP に、HP をもう 1 段の HP に通す（ch あたり 3 段）。
  - 低域 L = LP₂(LP₁(x))、高域 H = HP₂(HP₁(x))
- LR4 の性質: L と H は全周波数で **同相**、`|L| + |H| = 1`、L + H は振幅が平坦なオールパス。
  このため子音のゲイン g（0〜1）を掛けた `L + g·H` の振幅は `(1 + g·r⁴)/(1 + r⁴)`
  （r = tan(πf/fs) / tan(π·FREQ/fs)）で、g = 1 で平坦、g を下げると FREQ から上がなめらかに沈むシェルフ状になり、
  クロスオーバー付近にこぶやくぼみが出ない（§5 で確認）。グラフもこの式で描く。
- g = 1 でも出力はオールパスの位相回転を受ける（振幅は平坦）。群遅延は FREQ 付近で約 0.07 ms（6.5 kHz）と小さく、
  音色への影響は聞き取れない程度。

### 3.3 子音リミッタ（高域のみ、先読み 2 ms）

先読み D = round(2 ms × fs)（固定）。L / H と入力（バイパス用）を D サンプル遅らせ、遅らせた H にゲインを掛ける。
ゲインの計算は ch ごとの「ゲインの鎖」2 本（L ch / R ch）で行う。

1. **目標ゲイン**（毎サンプル）: 検出値 s を
   - STEREO LINK ON: `s = max(|H_L|, |H_R|)`（両方の鎖に同じ s）
   - STEREO LINK OFF: L の鎖は `|H_L|`、R の鎖は `|H_R|`
   
   として `w = s > T ? T / s : 1`（T = 10^(THRESHOLD/20)、比率 ∞ のリミッタ、ハードニー）。
2. **ホールド**: 直近 D+1 サンプルの w の最小値（単調デック、O(1)。MyMaximizer と同じ）。
   高域の波形がゼロを横切っても（2 kHz で半周期 0.25 ms < 2 ms）ゲインが戻らないので、ゲインが波形の中でうねらない。
3. **アタック / リリース**（分岐型 1 極）: 下がる方向は時定数 ATTACK（0 ms なら即座）、戻る方向は時定数 RELEASE。
4. **平滑**: 直近 D+1 サンプルの移動平均（長さ 2 ms の直線的な下降・上昇）。
   ATTACK 0 ではホールドと平滑の窓が揃っているので、**ゲインは子音の山の 2 ms 前から下がり始め、山が出力に着く時点で
   下がり切っている**（高域が THRESH を超えない。波形を削らずに音量だけを下げるので、きれいに抑えられる）。
   ATTACK を長くすると、その分だけ下がるのが遅れ、子音の頭が THRESH を超えて通る（自然さを残す）。
5. **出力**: `y = L_d + g·H_d`（d = D サンプル遅らせたもの。g は ch ごと）。
6. GR（dB）= `20·log10(g)`。表示用に、ch ごとにメータ取得以降の最小 g（＝最大 GR）と高域ピーク（SIB）を記録する。

- STEREO LINK の切替: 鎖の状態はそのまま、次のサンプルから検出値だけが変わる。平滑（2 ms）を通るのでゲインは飛ばない。
- 抑える量に上限は設けない（THRESH −60 dB では高域がほぼ消える）。

### 3.4 LISTEN

出力を、遅らせた **高域 H_d（リミッタを掛ける前）** にする（L/R それぞれ）。FREQ で切り分けた子音の帯域がそのまま聴ける。
ON/OFF は 10 ms のクロスフェード。リミッタ・メータは LISTEN 中も普段どおり動く（GR・グラフで効き方を見ながら FREQ を決められる）。

### 3.5 レイテンシとバイパス

- `latencySamples` = D（MyFXAudioUnit が `latency` として秒で報告。MyDAW はトラックのインサートの遅延も補正する）。
- レイテンシは **バイパス中も変えない**: バイパス時は D サンプル遅らせた入力（INPUT GAIN の前）を出す。
  ON/OFF は 10 ms のクロスフェード（MyMaximizer と同じ）。
- バイパス中もフィルタとゲインの鎖は動かし続け、戻したときにクリックやゲインの飛びが出ないようにする。
  メータの IN/SIB はバイパス中も動き、GR は 0 を表示する。
- サンプルレートが変わったら D を再計算（`prepare`）。

### 3.6 エディタへの受け渡し（レンダースレッド → UI）

既存の `MyFXMeterPeaks` と同じ方式（ロックなし、32 bit 1 語ずつ）。

| 値 | 用途 |
|---|---|
| 入出力ピーク（IN は INPUT GAIN の後） | IN / OUT メータ、CLIP ランプ |
| 高域ピーク L/R（前回取得以降の最大） | SIB メータ |
| 最大 GR L/R（前回取得以降、dB） | GR メータ、帯域グラフの赤 |

エディタは表示中だけ 30 Hz で読み出す。帯域グラフの曲線は UI 側で §3.2 の式から計算する
（160 点、FREQ と g が変わったときだけ再計算）。

## 5. テスト

- **抑えていないときは平坦**: THRESH 0 dB・−20 dBFS のサイン（100 Hz〜18 kHz、FREQ 2k / 6.5k / 15k）で、
  出力の振幅が入力と ±0.01 dB 以内（LR4 の和が平坦であることの確認）。
- **子音だけ抑える**: FREQ 6.5 kHz・THRESH −30 dB に、−10 dBFS の 10 kHz サイン → 高域 H のピークが
  THRESH（±0.5 dB）に張り付き、出力は解析値 `|L(10k)|·A + T`（約 −22 dBFS。LR4 の低域側が 10 kHz でも
  −16 dB 残るため、THRESH ちょうどまでは下がらない）と ±0.5 dB で一致。同じ条件で 500 Hz のサインは変化なし
  （±0.1 dB）。2 つを混ぜた信号でも 500 Hz 成分は変わらない。
- **特性の形**: g を固定（0.5 / 0.1）したとき、`|L + g·H|` が全周波数で g（dB）〜0 dB の範囲にあり、
  単調に変化する。解析式とレンダリング結果が一致（±0.05 dB）。
- **先読み**: ATTACK 0 で、突然始まる大きな高域（バースト）でも、遅らせた高域 × g が最初のサンプルから THRESH を超えない。
  ATTACK 5 ms では最初に THRESH を超えて通り、その後下がる。
- **リリース**: RELEASE 5 / 10 / 50 ms で、その時定数で戻る（±10 %）。
- **GR の値**: −10 dBFS の 10 kHz サイン・FREQ 6.5 kHz・THRESH −20 dB で GR ≈ THRESH − 高域のピーク
  ＝ −20 − (−11.4) ≈ −8.6 dB（定常、±0.5 dB。10 kHz での |H| は −1.4 dB）。
- **STEREO LINK**: L だけに 10 kHz のバースト、R に 500 Hz → ON では R も同じ GR、OFF では R の GR は 0。
- **LISTEN**: 500 Hz はほぼ消え（−40 dB 以下）、10 kHz はそのまま（−1.4 dB）出る。
- レイテンシ: `latency` = D / fs（2 ms）。インパルスが D サンプル後に出る（バイパス中も同じ）。
- パラメータ変化（INPUT 0 → +12 dB、FREQ 2k → 15k、THRESH 0 → −60 dB、STEREO LINK・LISTEN・バイパスの切替）で
  隣接サンプル差の上限（クリックなし）。
- モノラル（1 ch）、状態の保存・復元、アドレス・identifier の重複なし、サンプルレート 44.1 / 48 / 96 kHz
  （96 kHz でも FREQ 15 kHz で安定）。
- `MyPlugInSnapshots` でエディタ PNG を確認（GR・SIB はテスト用の値を流し込んで描く）。
