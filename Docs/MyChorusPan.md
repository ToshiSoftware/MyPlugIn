# MyChorusPan 設計書

定番のギター用ペダルとラック機材を元にした、4 つのモードのモジュレーション系エフェクト。
CHORUS PEDAL・DIMENSION・FLANGER PEDAL・AUTO PAN をヘッダのメニューで切り替え（同時には使わない）、
INIT ボタンで今のモードを推奨の設定に戻す。少ない操作で、オーソドックスな音がすぐに出ることをねらう。
Sources: `Sources/MyChorusPan`、tests: `Tests/MyChorusPanTests`。

| 項目 | 値 |
|---|---|
| 名前 | MyChorusPan（MyDAW では "MyDAW: MyChorusPan"） |
| Subtype | `MChP`（一度決めたら変更不可。既存: MRev, MDly, MStp, MMax） |
| 型名プレフィックス | `ChorusPan...`（MyDAW は全ソースを 1 モジュールでコンパイルするため） |
| モード | Chorus Pedal、Dimension、Flanger Pedal、Auto Pan（ヘッダのメニュー。MyDelay と同じ部品） |
| レイテンシ | 0 |
| テール | 変調ディレイのモード: ディレイの最大値（2 × DELAY）＋フィードバックが −60 dB まで減る時間。Auto Pan: 0 |
| エディタ | 300 × 460 px（ボタンと SPEED ランプの行があるため、標準の 424 より高い） |

### 改訂履歴

- ドラフト 1: 初版（2026-10-10）。Chorus/Flanger と Auto Pan の 2 モード。
- ドラフト 2: 波形（Sine、Triangle、Saw、Square）、LFO WIDTH・STEREO WIDTH の意味、MIX の追加、FEEDBACK ±95 %、
  Auto Pan の等パワーを確定。テンポ同期は出音を確認してから（2026-10-10）。
- 実装 1（2026-10-10）: ドラフト 2 どおり実装。補足:
  - Auto Pan の等パワーは sin／cos で計算（√(1 ∓ p) は端で急に曲がり、端から離れるときにクリックが出た）。
  - 波形の角と DELAY の追従は 2 段の平滑化（S 字）。1 段だと動き始めで読み出し速度が急に変わり、波形に角（クリック）が出た。
  - モード切り替えのフェードは、ディレイへの入力にも掛ける（戻ったとき、遅れた音が途中から急に始まらないように）。
  - 値の表示は 6 文字以内（`0.60Hz`、`0.10ms`）。7 本のフェーダが 300 px に並ぶため。
- 実装（2026-10-10）: 4 のボタンを幅広の赤いボタン「BOOST」に（ユーザー指示）。
- ドラフト 6（2026-10-10）: Dimension を Arturia「Chorus DIMENSION-D」の説明書の構成に合わせる（ユーザー指示）。
  左右の入力を別々のディレイに、1〜3 をディレイ時間と揺れの組み合わせに、4 を 1〜3 と組み合わせる効果音の
  ブーストスイッチ（アドレス 23）に、推奨値は「1、4 オフ」。ディレイの中心のずらしは外した（§2.3、§3.3）。
- ドラフト 5（2026-10-10）: Dimension の MIX をほかのモードと同じ形に（ユーザー指示: 下で原音だけ、中央で 0.5／0.5、上で効果音だけ）。
  推奨値は 50 %。
- ドラフト 4（2026-10-10）: Dimension を変更（ユーザーの試聴: 実機はモノラルの入力でもダブラーのように左右に分かれて広がる。
  音量が Chorus より大きい）。効果音を左 = A − 0.5B、右 = B − 0.5A、ディレイの中心を 4.5／7.5 ms に、
  MIX 100 % を原音 0.7 ＋ 効果音 0.7 の等量に（§3.3）。
- ドラフト 3（2026-10-10）: ユーザー指示で 4 モード（CHORUS PEDAL、DIMENSION、FLANGER PEDAL、AUTO PAN）と INIT ボタンに。決定事項:
  - パラメータはモードごとに別に持つ（切り替えてもそれぞれの設定が残る。範囲はモードに合わせて狭める）。
    未コミットで保存済みのプロジェクトがないため、アドレスはモードごとの 10 番台に振り直す（§2）。
  - DIMENSION は本物と同じ 1〜4 のボタンで深さと速さを選ぶ。波形は三角波、左右の揺れは 180° で固定。
  - CHORUS PEDAL にはフィードバックを持たせない。
  - 推奨値は §2 の値で実装し、聞いて調整する。DIMENSION の MIX は 100 %（本物は常に効果が掛かった状態のため）。

## 0. 使い方（マニュアルの元）

- ヘッダのメニューでモードを選び、**INIT** を押すと、そのモードの定番の設定になる。そこから好みに合わせて動かす。
- **CHORUS PEDAL**: 揺れと厚みを加える。SPEED で揺れの速さ、DEPTH で深さ。MIX 50 % で原音と効果音が半々（ペダルと同じ）。
- **DIMENSION**: 揺れを感じさせずに、音を左右に広げる。1（控えめ）・2・3（いちばん深い）から選び、
  効果をさらに強くしたいときは BOOST（実機の 4）を一緒にオンにする。
- **FLANGER PEDAL**: ジェット機のようなうねり。FDBK を上げるとクセが強くなり、マイナスにするとくぼんだ響きになる。
- **AUTO PAN**: 音が左右に動く。Square は左右に交互に切り替わる。
- SPEED のランプは、今のモードの揺れと一緒に明滅する（明るいほど LFO が上側）。
- FX チャンネルで使うときは MIX 100 %。トラックに直接挿すときは推奨値のまま（MIX 50 %）。

- エディタが閉じているときは読まない。

## 3. 信号処理

### 3.1 LFO（全モード共通の部品）

- 位相 φ（0〜1）を毎サンプル SPEED / サンプルレートだけ進める。値は −1〜+1。
  Sine と Triangle は 0 から上がり始め、Saw は −1 から上がって一気に戻り、Square は前半 +1。
- Saw の戻りと Square の切り替わりは、2 段の平滑化（各 2 ms、Auto Pan は各 5 ms）で S 字につなぐ（クリック防止）。
  Square のコーラスは、切り替わりのたびに短く音程が揺れる（ペダルの矩形波と同じ性質で、クリックではない）。
- SPEED の変更は位相を連続のまま速さだけ変え、50 ms でなめらかに追従。`reset()` で位相は 0 に戻る。

### 3.2 Chorus Pedal・Flanger Pedal（変調ディレイ）

- L と R がそれぞれ自分のディレイライン（最大 60 ms）を持ち、入力の左右を混ぜない。
- ディレイ時間 = DELAY × (1 + DEPTH × LFO)。R の LFO は L より L.WID × 180° ずらす。最短 3 サンプルで止める。
- 読み出しは 4 点エルミート補間。フィードバック（Flanger のみ）は ±95 % で、書き込む値は 1.25 へ向けてなだらかに抑える。
- 効果音に ST.WID（M/S の Side を 0〜1 倍）、最後に MIX で原音と混ぜる。
- DEPTH・FDBK・MIX・幅は 20 ms、DELAY は 2 段（各 20 ms）の S 字で追従。

### 3.3 Dimension

Arturia「Chorus DIMENSION-D」の説明書のシグナルフローに合わせた構成（ドラフト 6）:

- 左の入力はディレイ A、右の入力はディレイ B に入る（左右別々。モノラルの入力なら同じ音が入る）。
  1 つの三角波 LFO で、A と B を**逆向き**に揺らす。ディレイと揺れの幅は 1〜3 のボタンで決まる（§2.3）。
- **クロスミックス**: 左 = A − 0.5 × B、右 = B − 0.5 × A。各チャンネルに自分の効果音を足し、相手の効果音を
  逆相にして混ぜる（説明書:「互いのチャンネルを逆相にしたものをミックス」）。音程の揺れが一部打ち消し合う。
- 効果音に ST.WID（Side の量。説明書の STEREO WIDTH と同じく効果音の広がり）を掛け、MIX で原音と混ぜる
  （下で原音だけ、中央で 0.5／0.5、上で効果音だけ。説明書の MIX と同じく 0.5 が実機のバランス）。
- 4 がオンのとき: 効果音 ×√2（+3 dB）、原音 ×1/√2（−3 dB）。
- モノラルのノイズを入れたとき: 1〜3 で左右の相関 +0.1（50 ms ごとに見ても +0.03〜+0.36）、大きさ約 −3 dB
  （Chorus Pedal の推奨値は +0.55、−3.4 dB）。4 をオンにすると相関 −0.44（クロスミックスの逆相が強く出る）、−2 dB。
- ボタンの切り替えでは、ディレイ（2 段の S 字）・揺れ・4 のゲインがなめらかに移る（クリックなし）。
- 説明書にあるコンプレッサー／エクスパンダーとシェルビングフィルタ（BBD の雑音対策）は入れていない。
- 試した構成: 効果音を A − B だけにして左右逆相で足す形（ドラフト 3）は、左右が完全に逆相になり（相関 −0.24）、
  Chorus より 6 dB 大きかった。2 本のディレイの中心を 4.5／7.5 ms にずらす形（ドラフト 4）は、実機の構造に合わせて外した。

### 3.4 Auto Pan

- 位置 p = WIDTH × LFO（−1 = 左、+1 = 右）。角度 θ = 45° × (1 + p) として、左 = √2 cos θ、右 = √2 sin θ を掛ける。
  中央で左右とも 1（そのまま）、端で片側 +3 dB、反対側は無音。左右の合計の大きさは常に一定（等パワー）。
- ステレオの入力は、左右それぞれの音量を動かす。

### 3.5 モードの切り替え

出力を 10 ms でフェードアウト → 切り替え（ディレイラインを空にし、追従中の値を新しいモードの値に合わせる）→ 10 ms でフェードイン。
フェードはディレイへの入力にも掛けるので、遅れた音は無音から始まる。

### 3.6 エディタへの受け渡し

カーネルが今のモードの LFO の位相と波形を 32 ビットの値で公開し、エディタが 60 Hz で読む（§1.2）。

## 5. テスト

- LFO: 波形の値と周期、SPEED を変えても位相が跳ばない。
- Chorus・Flanger: DEPTH 0 % で固定の遅延、ディレイ時間が DELAY ±DEPTH の範囲で動き、L.WID 100 % で右が逆向き。
- Flanger: フィードバック ±95 % で発散しない。ST.WID 0 % で効果音がモノラル。MIX 0 % で原音そのまま。
- Dimension: モノラルの入力が左右に分かれて広がる（相関 −0.05〜+0.35）、MIX 50 % で約 −3 dB（1〜3）。4 で音量が上がり左右がさらに離れる。左だけの入力では、右には左の効果音が逆相・半分で出る（クロスミックス）。MIX 0 % で原音そのまま、ST.WID 0 % で左右が一致。ボタンの切り替えでクリックが出ない。
- Auto Pan: WIDTH 0 % で原音そのまま、端で片側が無音、左右の合計の大きさが一定、角がなめらか。
- INIT: 今のモードのパラメータだけが推奨値に戻る。
- パラメータ・モードの切り替えでクリックが出ない。表示文字列の往復。AU のパラメータ一覧とエディタの大きさ。

## 6. 今後

- テンポ同期（SPEED を BPM に合わせる）は、出音を確認してから検討する。パラメータは各モードの 10 番台の空きに足す。
